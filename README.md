# English Premier League Knowledge Base

This is my 2nd Project knowledge base, where I will introduce a 20-page website about the English Premier League.

## Contents 

- Website Homepage 
- about file 
- references file 
- README file
- 6 chosen categories (History, Competitions & Rules, Clubs, Players, Records, Hall of Fame), a total of 20 articles.

## Editing and publishing

Edit Markdown files inside the content folder using Obsidian. Each page begins with a YAML title and date. Use GitHub Desktop to commit and push changes. Use GitHub to publish the website.
